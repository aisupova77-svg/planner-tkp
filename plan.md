# План реализации — тестовый планировщик ТКП

## Правила реализации

- Стек: статический HTML, CSS и JavaScript без зависимостей.
- Данные: предзаполненный набор + `sessionStorage`; пользовательская сделка исчезает при закрытии вкладки.
- Проверка: после каждого этапа — ручной smoke-test и проверка синтаксиса JavaScript.
- Коммиты: один завершённый этап — один коммит.

## Этапы

1. **Каркас и дизайн-система** — адаптивный layout, светлая/тёмная тема, навигация, демонстрационные данные.
   - Проверка: все разделы открываются, тема меняется, мобильная ширина не ломает layout.
2. **Обзор, сделки и карточка** — KPI, реестр, фильтрация, одна тестовая сделка, статусы, журнал изменений.
   - Проверка: создание второй тестовой сделки заблокировано; редактирование меняет KPI и историю.
3. **Шкала и финансовая сводка** — события, помесячные показатели, график, просрочки, отчёты.
   - Проверка: даты сделки влияют на нужные показатели и красные предупреждения.
4. **Калькулятор и документы** — скидка, маржа, премия, печатное ТКП, экспорт CSV/JSON.
   - Проверка: тестовые формулы и файлы экспорта дают ожидаемый результат.
5. **Настройки и финальная QA-проверка** — JSON-восстановление, демоданные, адаптивность, доступность.
   - Проверка: сессия сбрасывается при новой вкладке, JSON валидируется, все ключевые сценарии проходят.
6. **Публикация** — создать удалённый GitHub-репозиторий, отправить историю, включить GitHub Pages.
   - Проверка: публичный URL открывает приложение.
